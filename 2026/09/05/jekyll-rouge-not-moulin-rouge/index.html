Jekyll Rouge Not Moulin Rouge

Created: 2026-09-05 Last updated: 2026-09-05 05:59

In the pursuit of improving codeblocks for the website I learnt that Jekyll uses Rouge to handle syntax highlighting of code snippets! This is called that because it uses a programming language called Ruby - not named after the movie Moulin Rouge!
